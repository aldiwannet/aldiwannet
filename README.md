# الديوان للمطورين · AlDiwan for Developers

نبني أدوات مفتوحة تساعد المطورين على استكشاف الشعر العربي وتقديمه في تجارب رقمية جميلة، دقيقة، وآمنة.

We build open developer tools for exploring and presenting Arabic poetry with correct typography, explicit API contracts, and production-minded examples.

## ابدأ البناء · Start building

| المشروع | ما يقدمه |
| --- | --- |
| [`aldiwan-api-spec`](https://github.com/aldiwannet/aldiwan-api-spec) | عقد OpenAPI ومجموعة Postman للواجهة العامة |
| [`aldiwan-flutter`](https://github.com/aldiwannet/aldiwan-flutter) | SDK typed وموثوق لـDart وFlutter |
| [`aldiwan-flutter-starter`](https://github.com/aldiwannet/aldiwan-flutter-starter) | تطبيق Flutter RTL متكامل كنقطة انطلاق احترافية |

يدعم الكتالوج القصيدة العمودية، النثرية، وقصيدة التفعيلة، مع وجوب الحفاظ على بيانات النسب التي تعيدها الواجهة.
